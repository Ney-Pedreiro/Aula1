## CODIGOS

### Clona o arquivo do site pro pc
git clone https do codigo

### Cria branch
git checkout -b nome-da-branch

### Lançar alterações para o github
git add .
git commit -m "texto explicando o commit"
git push (lança a mudança para o github)

### Lançar alteração da branch pro main!
git push --set-upstream origin nome da branch

### Atualizar branch com base na Main
git fetch upstream
git checkout main
git merge upstream/main
